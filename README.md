# Онлайн магазин для торговой сети HP_HALAL

Учебный веб-проект разработанный в команде из двух человек. Представляет собой веб-приложение для автоматизации заказов торговой сети с разграничением прав доступа под три роли (администратор, торговая точка, клиент).

## Ролевая модель приложения:
### Клиент:
* Возможность оформления заказа.
* Просмотр каталога.
* Возможность дополнять состав продукта в корзине.
* Оставлять отзыв на торговую точку.

### Торговая точка:
* Оформлять заказ через себя.
* Просмотр поступивших заказов.
* Просмотр отзывов по готовым заказам.

### Администратор:
* CRUD-система: категорий, товаров, добавок, сотрудников, торговых точек.
* Создание отчета за выбранный период в формате PDF.
* Просмотр статистики спроса.

## Стек технологий:
* **Backend:** PHP (Laravel)
* **Database:** MySQL
* **Frontend:** JavaScript, HTML, CSS
* **Локальное окружение:** Open Server Panel 6 (или XAMPP/Docker)

## Реализованный функционал:
* **Ролевая модель: Разделение пользователей на клиентов и администратора**
* **Авторизация: Безопасная регистрация и вход в систему (Хэширование паролей, валидация вводимых значений, вывод ошибок)**
* **Панель администратора: Реализованна полноценная CRUD-система для категории товаров (просмотр, добавление, редактирование удаление)**
* **Командная разработка: Совместное проектирование БД и разделение обязанностей равномернно**

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/pchel23/HP-Halal.git
   cd HP-Halal
   ```
2. Установите зависимости Backend:
   ```bash
   composer install
   ```
3. Создайте файл окружения из шаблона:
   ```bash
   cp .env.example .env
   ```
   *В файле `.env` укажите доступы к вашей БД в Open Server*
4. Сгенерируйте ключ приложения:
   ```bash
   php artisan key:generate
   ```
5. Запустите миграции вместе с сидeрами (автозаполнение БД):
   ```bash
   php artisan migrate --seed
   ```
6. Запустите локальный сервер (если не используете домен Open Server):
   ```bash
   php artisan serve
   ```
